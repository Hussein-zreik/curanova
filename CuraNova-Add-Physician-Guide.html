How to Give a Doctor Access

CuraNova Physician Portal  ·  about 2 minutes per doctor  ·  repeat these steps for every new doctor

👋Do this every time you add a new doctor. Each doctor gets their own login and their own one-line entry in the system. When you finish, that doctor can sign in and see only their own patients — nobody else's.
1
Create login

Make the doctor a login

In Supabase, go to Authentication → Users → Add user → Create new user.

Type the doctor's email and a password, tick Auto Confirm User, then click Create user.

🔑The password you type here is the doctor's access code. Write it down — you'll give it to them at the end. Use a different password for each doctor.
2
Open SQL

Open a fresh query

Go to SQL Editor and click + New query.

❓New doctor = new query. Always click + New query for each doctor (or clear the box first). Do not edit a previous doctor's line — start fresh each time. One doctor = one line, run on its own.
3
Mark as doctor

Tell the system this email is a physician

Paste this in, change the 3 highlighted values, then click Run:

-- change the 3 highlighted values, then Run
insert into profiles (id, role, physician_name, full_name)
select id, 'physician', 'Haddad', 'Dr. Elie Haddad'
from auth.users
where email = 'doctor@email.com'
on conflict (id) do update
  set role = excluded.role,
      physician_name = excluded.physician_name,
      full_name = excluded.full_name;
  • doctor@email.comThe doctor's email — exactly the same one you typed in Step 1.
  • HaddadThe doctor's name exactly as your nurses type it in the patient's "Referring physician" box.
  • Dr. Elie HaddadThe doctor's full name — this is just how their name is shown on screen.
⚠️The middle value (Haddad) is the important one. It must match the referring-physician name on the patients — if it doesn't match anything, the doctor will correctly see no patients at all.
4
Check

Make sure it worked

Click + New query, paste this (change the email to the same one), and Run:

select u.email, p.role, p.physician_name
from auth.users u left join profiles p on p.id = u.id
where u.email = 'doctor@email.com';

✅ You should see physician under role.   ❌ If it says null, the line didn't run — go back to Step 3 and Run it again.

5
Send

Give the doctor 3 things

Send the doctor these three things — that's all they need:

  • 1The website link to CuraNova.
  • 2Their email.
  • 3Their password (the access code from Step 1).
✅They open the link, enter their email and password, and they're in — seeing only their own patients, read-only. If they were already signed in, they should sign out and back in once.
Copy this

📋 The exact text to add — for every new doctor

For each new doctor, open a + New query, paste this whole block, change only the 3 highlighted values, then click Run:

insert into profiles (id, role, physician_name, full_name)
select id, 'physician', 'Haddad', 'Dr. Elie Haddad'
from auth.users
where email = 'doctor@email.com'
on conflict (id) do update
  set role = excluded.role,
      physician_name = excluded.physician_name,
      full_name = excluded.full_name;
  • doctor@email.com→ the new doctor's email (the one you made in Step 1).
  • Haddad→ the doctor's name exactly as nurses type it in "Referring physician".
  • Dr. Elie Haddad→ the doctor's full name shown on screen.

Same query or a new one?

A new one, every time. Each doctor is one separate line with their email and name. Click + New query for each doctor. Never pile several doctors into one line, and never overwrite an old doctor's entry.

Remove or change a doctor

  • Remove access: Authentication → Users → delete the user (or change their password).
  • Change what they see: re-run Step 3 with a different middle name value.
