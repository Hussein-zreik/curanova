Give a Doctor Access — Cheat Sheet

CuraNova Physician Portal · one setup, then ~1 minute per doctor

DO ONCE

Turn the feature on

You only ever do this a single time.

  1. 1
    In Supabase, open SQL Editor → New query.
  2. 2
    Open the file physician-portal-setup.sql, copy everything, paste it in, and click Run.
    You should see “Success.” It won’t affect your patient data or your nurses’ login.
✅Done — forever. You never touch this part again.
PER DOCTOR

Add a doctor

Repeat these 3 steps for each doctor. Their password is their access code.

  1. 1
    Make their login. Authentication → Users → Add user → Create new user. Enter their email and a password, tick Auto Confirm User, then Create.
    The password you type here is the code you’ll give the doctor.
  2. 2
    Mark them as a physician. Open SQL Editor → New query, paste the line below, change the 3 green values, and Run: 
    -- change the 3 green values, then Run
insert into profiles (id, role, physician_name, full_name)
select id, 'physician', 'Haddad', 'Dr. Elie Haddad'
from auth.users where email = 'doctor@email.com';
    Haddad = the doctor’s name exactly as your nurses type it in “Referring physician”.
  3. 3
    Send the doctor 3 things: the website link, their email, and their password. They open the link, enter both → they’re in.
🔑The code for a doctor is simply the password you set in Step 1 — it’s different for each doctor, so you can revoke one without affecting the others.

What the doctor sees

  • Only their own patients — nobody else’s.
  • Read-only: trajectories, photos, alerts, Print / Save PDF.
  • Can add a sign-off note for the nursing team.
  • Cannot edit records or open the assessment tools.

Remove or change a doctor

  • Revoke: Authentication → Users → delete the user, or change their password.
  • Change what they see: edit their physician_name in the profiles table.
